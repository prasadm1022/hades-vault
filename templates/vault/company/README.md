# Company (vault)

What this company has learned that holds for every organization. The engine's `company/` policies
stay generic; this folder adds to them and never contradicts them.

| Path | Contents |
|---|---|
| `staff/<role>.md` | notes for the four company staff roles: model override, company-wide notes |
| `knowledge/lessons.md` | lessons true for every organization; engine upstream candidates |
| `playbooks/tech/<tech>.md` | learned technology playbooks |
| `playbooks/stacks.json` | learned detection fingerprints, merged over the engine's by `hades detect` |

Promotion team -> organization -> company: `{{ENGINE}}/company/knowledge-policy.md`.
